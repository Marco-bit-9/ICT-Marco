# ICT Marco — Project Akhir Informatika Kelas 8

Website profil Marco dan Keanu, ditulis dalam HTML dan CSS eksternal tanpa JavaScript.

- `index.html`: profil Marco
- `index2.html`: profil Keanu
- `styles.css`: gaya Marco
- `styles1.css`: gaya Keanu
- `assets/`: ilustrasi lokal dan favicon

Kedua halaman dihubungkan lewat gambar profil dan tautan footer. File disimpan di root untuk deployment statis Vercel.

**Sebelum pengumpulan:** Ganti `assets/marco-profile.svg` dan `assets/keanu-profile.svg` dengan foto siswa memakai seragam sekolah, kemudian perbarui `src` dalam HTML. Contoh tugas sekolah juga meminta foto offline lainnya; ilustrasi saat ini adalah pengganti sementara.

Data pribadi yang terlalu rinci (alamat tempat tinggal dan tanggal lahir lengkap) disederhanakan pada versi yang di-host secara publik.
